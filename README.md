# Favorit Parts Search

Веб-приложение для поиска автозапчастей по артикулу через API Favorit Parts. Позволяет выбирать производителя, просматривать найденные детали и их аналоги, сравнивать складские предложения по цене и наличию.

[ДЕМОНСТРАЦИЯ](https://favorit-parts.pages.dev/)

## Разработка

### Стек

- React 19
- JavaScript (JSX)
- Redux Toolkit
- Vite 8
- SCSS Modules

### Особенности реализации

Поиск выполняется в два этапа: сначала загружается список производителей по артикулу, затем товары выбранного производителя вместе с аналогами и складскими предложениями.

Результаты доступны в двух представлениях: карточки товаров с предложениями складов и общая таблица предложений. Реализованы сортировка по цене и остатку, клиентская пагинация и адаптивный интерфейс.

Для управления данными и асинхронными запросами используется Redux Toolkit. Предусмотрены отмена устаревших запросов и обработка состояний загрузки и ошибок.

**Структура проекта:**

- `src/modules/parts-search/` — логика поиска и компоненты результатов.
- `src/services/` — взаимодействие с API.
- `src/ui/` — переиспользуемые UI-компоненты.
- `src/shared/` — общие утилиты и хуки.
- `src/styles/` — стили, шрифты и токены оформления.

### Установка и запуск

Требуются Node.js 20.19+ или 22.12+ и Yarn 4.5.0.

Установить зависимости:

```sh
yarn install
```

Скопировать `.env.example` в `.env.local`. Файл содержит необходимые переменные для подключения к API.

Запустить приложение:

```sh
yarn dev
```

Приложение будет доступно по адресу [http://localhost:5173](http://localhost:5173) или следующему свободному порту.

### Сборка

```sh
yarn build
```

Создаёт production-сборку в директории `dist`.

```sh
yarn preview
```

Запускает локальный просмотр production-сборки.
